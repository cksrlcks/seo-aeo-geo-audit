# 보고서 스타일 가이드

`scripts/report.css` 가 이 문서를 그대로 구현한다. 색 · 글자 · 간격은 아래 토큰만 쓴다. 새 표현이 필요하면 이 문서에 먼저 추가하고 CSS 에 반영한다.

양식을 고칠 때는 점검을 다시 돌리지 않고 저장된 JSON 으로 다시 그려 본다: `node scripts/render.mjs <audit-....json> [출력 경로(확장자 제외)]`.

## 원칙

- **전문 보고서의 절제** — 구조색은 남색 하나다. 표지, 표 머리 행, 소제목 표시가 남색이다. 테두리로 가두지 않는다. 박스 대신 여백과 가는 가로선으로 나누고, 면이 필요하면 테두리 없는 옅은 바탕(안내 배너, 우선순위 카드)만 쓴다.
- **판정은 신호등** — 녹색 · 주황 · 빨강은 판정과 점수 구간에만 쓴다. 판정은 굵은 판정색 글자로 쓰고 점(●)을 붙이지 않는다. 글자가 판정을 말하므로 색만으로 말하지 않는다.
- **쪽이 단위** — 표지, 한눈에 보기, 각 섹션, 개선 로드맵, 부록은 모두 새 쪽에서 시작한다. 쪽마다 머리글 · 바닥글 구분선과 쪽 번호가 있다.
- **한 문서, 두 매체** — 쪽으로 나눈 같은 DOM 을 HTML 로 저장하고 PDF 로 인쇄한다. 화면과 종이의 쪽 구성이 같다.
- **문장형 표기** — 대문자 강조, 자간 넓힘, 장식용 라벨을 쓰지 않는다. 섹션 부제는 질문형(“~인가”)이 아니라 명사형(“~여부”, “~상태”)으로 끝낸다.
- **말줄임 금지** — 보고서의 어떤 문구도 “…”로 자르지 않는다. 길면 줄바꿈하고, 예시가 필요하면 조건에 맞는 문장 중 가장 짧은 것을 통째로 쓴다. 여러 개를 다 보일 수 없으면 앞의 몇 개와 “외 N개”로 쓴다.
- **설명은 줄을 나눈다** — 항목명과 설명을 대시(—)로 이어 붙이지 않는다. 항목명 다음 줄에 설명을 둔다.
- **한 내용은 한 곳에** — 같은 점수 · 정보를 한 쪽 안에서 두 번 보이지 않는다(예: 표지에는 점수를 두지 않고 한눈에 보기에만 둔다).

## 글자

서체는 Pretendard 하나(jsDelivr)이고, 받을 수 없으면 맑은 고딕, Apple SD Gothic Neo 순으로 대체한다. 본문 자간 −0.01em, 숫자는 `tabular-nums`.

- 본문의 모든 숫자 묶음은 쪽 나누기 직전에 `<span class="n">` 으로 감싸 자간 −0.03em 을 준다(SVG 안 제외). 그래서 CSS 에서 `X span` 처럼 넓은 선택자를 쓰지 않는다 — 숫자 span 까지 잡힌다. `X > span:not(.n)` 처럼 좁힌다.
- 큰 숫자(점수, 지표 값, 건수)는 −0.05 ~ −0.07em, `proportional-nums`. 고정폭이면 “1” 앞에 빈 공간이 생겨 왼쪽 정렬이 틀어져 보인다.

| 토큰 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| `--t-display` | 30pt | 800 | 표지의 점검 대상 도메인 |
| `--t-num` | 28pt | 300 | 섹션 번호(01 ~ 07) |
| `--t-score` | 24pt | 800 | 섹션 점수, 지표 카드 값, 우선순위 건수 |
| `--t-title` | 20pt | 800 / 600 | 섹션 제목(h2), 종합 점수 구간 / 표지 제목 |
| `--t-section` | 12pt | 700 / 400 | 소제목(h3), 영역 점수 / 섹션 부제 |
| `--t-body` | 10pt | 400 / 500 / 700 | 본문 / 안내 배너 / 박스 제목(h4) |
| `--t-table` | 9pt | 400 / 700 | 표, 박스 목록, 콜아웃, 단위(점) |
| `--t-caption` | 8pt | 400 / 700 | 머리글 · 바닥글, 표 보조 줄, 지표 라벨, 뱃지, pill, 점수표 머리 행 |

원형 차트 안에는 점수 숫자만(30pt 800, 가운데). 단위 “/ 100” 은 넣지 않는다.

## 쪽 (A4)

| 영역 | 규격 |
|---|---|
| 쪽 | 210 × 297mm, 좌우 여백 16mm |
| 머리글 | 위 15mm. 왼쪽 “도메인 \| 보고서명”, 오른쪽 그 쪽의 섹션 이름(남색 700, 번호와 이름 사이 공백 두 칸 유지). 아래 1px 선 |
| 본문 | 머리글 아래 24px 부터 바닥글 위까지. 바닥 5mm 는 비워 둔다(HTML 을 오프라인에서 열어 글꼴이 바뀌어도 넘치지 않게) |
| 바닥글 | 아래 15mm. 위 1px 선, 왼쪽 작성자(없으면 도구명), 오른쪽 “쪽 / 전체 쪽”(700) |

- 쪽 순서: 표지 → 한눈에 보기 → 01 ~ 07 섹션 → 개선 로드맵 → 부록. 모두 새 쪽에서 시작한다.
- 표는 행 단위로 다음 쪽에 이어지고 머리 행을 반복하며, 다음 쪽 맨 위에 “앞 쪽 표에서 이어집니다”를 표시한다. 이 쪽에 두 행 미만이 남거나 다음 쪽에 한 행만 넘어가면 그렇게 나누지 않는다. 목록은 항목 단위로 이어진다.
- 그 밖의 블록(섹션 머리, 점수표, 지표 카드, 박스 2단, 콜아웃)은 쪼개지 않는다. 섹션 머리 · 소제목은 다음 블록과 같은 쪽에 둔다.
- 화면에서는 어두운 `--canvas` 위에 그림자 진 종이로 쪽마다 48px 떨어져 보인다. 창 폭이 쪽보다 좁으면 쪽 전체를 축소한다. 상단 남색 도구 막대에 전체 쪽수와 인쇄 버튼이 있고, 인쇄할 때는 숨긴다.
