# 보고서 스타일 가이드

`scripts/report.css` 가 이 문서를 그대로 구현한다. 색 · 글자 · 간격은 아래 토큰만 쓴다. 새 표현이 필요하면 이 문서에 먼저 추가하고 CSS 에 반영한다.

## 원칙

- **전문 보고서의 절제** — 구조색은 남색 하나다. 표지, 표 머리 행, 섹션 구분선, 소제목 표시가 남색이다. 연한 색 면, 둥근 카드, 장식은 쓰지 않는다.
- **판정은 신호등** — 녹색 · 주황 · 빨강은 판정과 점수 구간에만 쓴다. 판정은 항상 점(●) + 굵은 글자로 쓰므로 색만으로 말하지 않는다.
- **쪽이 단위** — 표지, 한눈에 보기, 각 섹션, 개선 로드맵, 부록은 모두 새 쪽에서 시작한다. 쪽마다 머리글 · 바닥글 구분선과 쪽 번호가 있다.
- **한 문서, 두 매체** — 쪽으로 나눈 같은 DOM 을 HTML 로 저장하고 PDF 로 인쇄한다. 화면과 종이의 쪽 구성이 같다.
- **문장형 표기** — 대문자 강조, 자간 넓힘, 장식용 라벨을 쓰지 않는다.
- **말줄임 금지** — 보고서의 어떤 문구도 “…”로 자르지 않는다. 길면 줄바꿈하고, 예시가 필요하면 조건에 맞는 문장 중 가장 짧은 것을 통째로 쓴다. 여러 개를 다 보일 수 없으면 앞의 몇 개와 “외 N개”로 쓴다.
- **설명은 줄을 나눈다** — 항목명과 설명을 대시(—)로 이어 붙이지 않는다. 항목명 다음 줄에 설명을 둔다.

글자로 쓰는 색은 모두 흰 바탕 대비 4.5:1 이상이다.

## 글자

서체는 Pretendard 하나(jsDelivr)이고, 받을 수 없으면 맑은 고딕, Apple SD Gothic Neo 순으로 대체한다. 숫자는 `tabular-nums`, 자간 −0.01em.

| 토큰 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| `--t-display` | 30pt | 800 | 표지의 점검 대상 도메인 |
| `--t-num` | 28pt | 300 | 섹션 번호(01 ~ 07) |
| `--t-score` | 24pt | 800 | 섹션 점수, 지표 카드 값 |
| `--t-title` | 20pt | 800 / 600 | 섹션 제목(h2), 종합 점수 구간 / 표지 제목 |
| `--t-section` | 12pt | 700 / 400 | 소제목(h3), 영역 점수 / 섹션 부제(측정 조건 질문) |
| `--t-body` | 10pt | 400 / 700 | 본문, 섹션 결과 문장 / 박스 제목(h4) |
| `--t-table` | 9pt | 400 / 700 | 표, 박스 목록, 콜아웃, 섹션 설명 |
| `--t-caption` | 8pt | 400 / 700 | 머리글 · 바닥글, 표 보조 줄, 지표 라벨 |

원형 차트 안 숫자는 36px 800, “/ 100” 은 10px 700.

## 간격 · 모서리

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--s-1` | 4px | 줄 사이 미세 간격 |
| `--s-2` | 8px | 표 칸 여백, 카드 사이, 머리글 · 바닥글 선 안쪽 |
| `--s-3` | 12px | 블록 사이(쪽 본문의 기본 간격), 카드 안 여백 |
| `--s-4` | 16px | 소제목 위 추가 간격, 박스 · 콜아웃 좌우 여백 |
| `--s-5` | 24px | 점수표 여백, 본문 시작 여백 |
| `--s-7` | 48px | 화면의 쪽 사이 |
| `--r-2` | 4px | 버튼 |

카드, 박스, 표, 쪽에는 모서리를 주지 않는다.

## 쪽 (A4)

| 영역 | 규격 |
|---|---|
| 쪽 | 210 × 297mm, 좌우 여백 16mm |
| 머리글 | 위 15mm. 왼쪽 “도메인 \| 보고서명”, 오른쪽 그 쪽의 섹션 이름(남색 700). 아래 1px 선 |
| 본문 | 머리글 아래 24px 부터 바닥글 위까지. 바닥 5mm 는 비워 둔다(HTML 을 오프라인에서 열어 글꼴이 바뀌어도 넘치지 않게) |
| 바닥글 | 아래 15mm. 위 1px 선, 왼쪽 작성자(없으면 도구명), 오른쪽 “쪽 / 전체 쪽”(700) |

- 쪽 순서: 표지 → 한눈에 보기 → 01 ~ 07 섹션 → 개선 로드맵 → 부록. 모두 새 쪽에서 시작한다.
- 표는 행 단위로 다음 쪽에 이어지고 머리 행을 반복하며, 다음 쪽 맨 위에 “앞 쪽 표에서 이어집니다”를 표시한다. 이 쪽에 두 행 미만이 남거나 다음 쪽에 한 행만 넘어가면 그렇게 나누지 않는다. 목록은 항목 단위로 이어진다.
- 그 밖의 블록(섹션 머리, 점수표, 지표 카드, 박스 2단, 콜아웃)은 쪼개지 않는다. 섹션 머리 · 소제목은 다음 블록과 같은 쪽에 둔다.
- 화면에서는 어두운 `--canvas` 위에 그림자 진 종이로 쪽마다 48px 떨어져 보인다. 창 폭이 쪽보다 좁으면 쪽 전체를 축소한다. 상단 남색 도구 막대에 전체 쪽수와 인쇄 버튼이 있고, 인쇄할 때는 숨긴다.

## 컴포넌트

| 이름 | 클래스 | 규격 |
|---|---|---|
| 섹션 머리 | `.sec-head` | 왼쪽에 번호(`--t-num` 300 남색) → 제목(h2) → 부제(질문). 오른쪽 34mm 점수 블록(숫자 + “/ 100” + 구간 + 4px 막대). 아래 2px 남색 선, 그 아래 결과 문장(`--ink`)과 설명(`--ink-3`) |
| 종합 점수표 | `.score-card` | 3px 남색 윗선 + 1px 테두리. 원형 차트(132px, 선 12/120, 구간색) → “종합 점수” 캡션 + “N점 · 구간”(`--t-title`, 구간색) + 설명 → 세로 구분선 뒤 SEO · AEO · GEO 점수와 4px 막대 |
| 지표 카드 | `.stats` > `.stat--{tone}` | 4칸 같은 폭, 1px 테두리 + 3px 판정색 윗선. 값(`--t-score` 800) + 단위 + 라벨 |
| 박스 2단 | `.duo` > `.box--good` · `.box--bad` | 흰 바탕, 1px 테두리 + 3px 판정색 윗선. 제목은 점 + 판정색 700(“잘 되어 있는 것”, “수정해야 할 것”). 항목은 두 줄: 항목명(700) 줄바꿈 후 “측정값 …, 권장 기준 …”(`--ink-3`) |
| 표 | `.tbl`, `.tbl--kv` | 머리 행 남색 바탕 흰 글자 700, 짝수 행 `--zebra`, 행 구분 1px, 칸 여백 8px, 첫 칸 `--ink` 700, 숫자 오른쪽 정렬. 보조 줄 `.sub`(캡션), 개선 방법 `.fix`(앞에 남색 “개선”) |
| 소제목 | `.sheet-body > h3` | 왼쪽 3px 남색 선 + 12pt 700 |
| 판정 | `.st` + `.tone-*` | 7px 점 + 700 글자, 줄바꿈 없음 |
| 콜아웃 | `.callout` | `--fill` 바탕, 왼쪽 3px 남색 선. 표지의 “보장하지 않는 것”, 부록의 “점검 시 참고” |

## 점검 결과 표 칸

| 칸 | 폭 | 내용 |
|---|---|---|
| 점검 항목 | 36mm | 항목명(700) + 가중치(보조 줄) |
| 측정값 | 24mm | 짧은 값(예: HTTP 200, 9/9 허용, 1,701자) |
| 권장 기준 | 27mm | 통과 기준(`--ink-3`) |
| 판정 | 15mm | 판정 점 + 글자 |
| 진단 내용 · 개선 방법 | 나머지 | 진단(`--ink-2`) + 주의 · 실패일 때 개선 방법(`.fix`) |
